[![Manifest](https://img.shields.io/badge/manifest-v3-blue)](https://developer.chrome.com/docs/extensions/mv3/)
[![Version](https://img.shields.io/badge/version-2.7.0-pink)](https://www.bilibili.com/)

[![Platform](https://img.shields.io/badge/platform-Chrome%20%2F%20Edge%20MV3-orange)](https://chromewebstore.google.com/)

> 一个基于 Manifest V3 的浏览器扩展，通过解析弹幕中的「空降」提示实现视频片段自动跳过，并附带自动连播、片头/片尾跳过、弹幕自动点赞等增强能力。

⚠️ **注意**：本项目为个人学习用途的第三方增强工具，与哔哩哔哩官方无任何关联。

## 功能特性

| 功能 | 说明 | 作用域 | 默认状态 |
| --- | --- | --- | --- |
| **弹幕自动跳过** | 解析弹幕中的时间/点击提示，自动跳转到目标时间点 | 全局（云端同步） | 开启 |
| **弹幕自动点赞** | 对命中的「空降」弹幕自动点赞 | 全局（云端同步） | 开启 |
| **跳过通知** | 跳过时在播放器顶部显示提示条 | 全局（云端同步） | 开启 |
| **自动连播** | 当前视频结束后自动播放下一个 | 当前页面 | 关闭 |
| **开头跳过** | 视频开始播放时自动跳过片头 N 秒 | 当前页面 | 关闭 |
| **结尾跳过** | 接近结尾时自动跳到下一个视频 | 当前页面 | 关闭 |

**弹幕自动跳过**支持的提示类型：

- **时间目标型**：弹幕中直接给出目标时间点，例如 `空降:01:01`、`跳伞02:30`、`工程 12:00`（可出现在关键词左边或右边）。
- **点击次数型**：弹幕给出「右键/右点 N 下」形式的提示，按 `每次点击秒数` 累计快进，例如 `右点十下`。

## 工作原理

扩展采用 Manifest V3 架构，由三部分协作完成：

1. **Background Service Worker（`background.js`）**
   - 作为网络请求代理，代为发起跨域请求（带 `Referer` 头）。
   - 实现 B 站 **WBI 签名**：内置 MD5 算法与 `WBI_MIXIN_KEY_ENC_TAB` 混淆表，对弹幕分段接口请求进行签名，绕过 API 校验。
   - WBI 密钥缓存 30 分钟，避免频繁请求。

2. **Content Script（`content.js`）** —— 核心逻辑
   - **弹幕获取**：优先通过 WBI 签名的 protobuf 接口（`x/v2/dm/wbi/web/seg.so`）获取弹幕，失败则回退到旧版 XML 接口（`x/v1/dm/list.so`）；内置 Protobuf 解析器，无需第三方依赖。
   - **弹幕解析（`DanmakuParser`）**：正则匹配关键词 + 时间/次数，支持中文数字（`一二三...十百千`）与多种时间格式（`mm:ss` / `hh:mm:ss` / `X分Y秒` 等）。
   - **分组合并（`groupMatches`）**：将多条相似弹幕按「发送时间接近度」与「目标时间接近度」合并为一组，取众数目标时间作为跳转依据，降低误跳概率。
   - **懒加载**：随播放进度动态拉取后续分段的弹幕（每分段 6 分钟）。
   - **跳过执行**：监听 `timeupdate` 事件，进入目标区间即 `video.currentTime = targetTime`，并去重防止重复跳过。
   - **视频切换检测**：通过 `loadeddata` 事件与 `history` API 监听，切换视频/选集后自动重置状态并重解析。

3. **Popup 设置面板（`popup.html` / `popup.css` / `popup.js`）**
   - 四个标签页：基础功能、弹幕跳过、关键词规则、高级设置。
   - 开关分两类：**全局配置**（`chrome.storage.sync` 云端同步）与**页面级状态**（`sessionStorage`，仅当前标签页生效）。

## 安装方式

### 方式一：从源码加载（开发者模式）

适用于 Chrome / Edge 等基于 Chromium 的浏览器：

1. 克隆或下载本仓库到本地：
   ```bash
   git clone <repo-url> bilibili-enhance-extension
   ```
2. 打开浏览器扩展管理页面：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
3. 右上角开启 **「开发者模式」**。
4. 点击 **「加载已解压的扩展程序」**，选择本仓库根目录（含 `manifest.json` 的文件夹）。
5. 固定扩展图标到工具栏，访问 B 站视频页即可使用。

### 方式二：打包安装

在扩展管理页点击「打包扩展程序」，选择根目录生成 `.crx`（需自行处理签名/分发）。

> 适用页面：`*://www.bilibili.com/video/*`、`*://www.bilibili.com/bangumi/play/*`、`*://www.bilibili.com/list/*`。

## 使用说明

1. 打开任意 B 站 **视频 / 番剧 / 合集** 播放页。
2. 点击扩展图标打开设置面板，按需开启功能：
   - **弹幕自动跳过 / 自动点赞**：全局开关，开启后对所有页面生效（同步到账号）。
   - **自动连播 / 开头跳过 / 结尾跳过**：页面级开关，仅对当前播放页生效，刷新或切换页面后重置。
3. 播放器工具栏「分享」按钮右侧会出现扩展入口（带四位状态徽章 `弹幕/连播/开头/结尾`，`1` 表示开启），点击可打开页内快速开关面板。
4. 命中跳转时，播放器顶部会显示跳过提示条（可在「弹幕跳过」标签页关闭）。

**状态徽章含义**（四位数字）：

```
第1位 弹幕自动跳过   (1=开 / 0=关)
第2位 自动连播       (1=开 / 0=关)
第3位 开头跳过       (1=开 / 0=关)
第4位 结尾跳过       (1=开 / 0=关)
```

## 配置项说明

### 弹幕跳过参数（高级设置 / 弹幕跳过标签页）

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 跳转起点延后 (`skipMarginStart`) | 3 秒 | 实际跳转时间 = 弹幕目标时间 + 该值 |
| 跳转终点提前 (`skipMarginEnd`) | 3 秒 | 实际跳转时间 = 弹幕目标时间 − 该值 |
| 最短跳过时长 (`minSkipDuration`) | 5 秒 | 小于该时长的跳过不执行 |
| 弹幕最大长度 (`maxDanmakuLength`) | 20 字 | 超过该长度的弹幕不参与匹配 |
| 右键快进秒数 (`secondsPerRightClick`) | 5 秒 | 「右点 N 下」每下跳过的秒数 |

### 分组容差（高级设置）

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 发送时间接近容差 (`groupFromTolerance`) | 5 秒 | 弹幕发送时间差小于该值视为同组 |
| 目标时间接近容差 (`groupToTolerance`) | 5 秒 | 弹幕目标时间差小于该值归为同一跳跃目标 |
| 已跳过判定容差 (`skippedTolerance`) | 2 秒 | 当前时间距目标小于该值认为已跳过，不再重复 |

### 数据管理

- **导出配置 / 导入配置**：以 JSON 形式备份与恢复全局配置。
- **恢复默认**：清空自定义设置。

## 弹幕匹配规则

扩展通过「关键词规则」识别可跳过的弹幕。内置默认规则如下：

| 规则名称 | 关键词 | 类型 | 方向 | 允许间隔 |
| --- | --- | --- | --- | --- |
| 跳伞/跳伞: | 跳伞, 跳伞: | 时间目标 | 左 | 否 |
| 右点/右键/右 | 右点, 右键, 右 | 点击次数 | 左 | 否 |
| 空降/空降: | 空降:, 空降 | 时间目标 | 左 | 否 |
| 绯红之王 | 绯红之王 | 时间目标 | 左 | 否 |
| 工程 | 工程 | 时间目标 | 右 | 是 |

**规则字段说明**：

- **类型 (`type`)**
  - `time_target`：从弹幕中提取目标时间点。
  - `click_count`：从弹幕中提取点击次数，跳转秒数 = 次数 × `secondsPerRightClick`。
- **关键词方向 (`keyword_direction`)**：`left`（关键词在时间点左侧，如 `空降:01:01`）、`right`（右侧，如 `01:01工程`）、`all`（两边均可）。
- **允许间隔 (`allow_gap`)**：是否允许关键词与时间之间夹带其它字符。

用户可在「关键词规则」标签页自行 **新增 / 编辑 / 删除** 规则，配置随全局设置云端同步。

## 权限与隐私

**声明的权限**

- `storage`：用于保存全局配置（`chrome.storage.sync`）。
- `host_permissions`：`api.bilibili.com`、`www.bilibili.com`，用于请求弹幕与接口数据。

**隐私说明**

- 全局配置（弹幕跳过相关）通过浏览器账号 **云端同步**，不会上传到任何第三方服务器。
- 页面级状态（连播/开头/结尾跳过）仅存于当前标签页的 `sessionStorage`，关闭即清除。
- 弹幕自动点赞需要登录态（读取 `bili_jct` Cookie），仅向 B 站官方接口发起点赞请求，点赞间隔约 1.5 秒以防风控。
- 扩展不收集、不上传任何个人隐私数据。

## 常见问题

**Q：为什么有的视频不跳过？**
- 弹幕接口可能限流或返回空，会按最多 3 次重试；仍失败则回退 XML 接口。
- 弹幕需包含可被规则匹配的关键词与时间/次数信息，普通弹幕不会触发跳过。
- 跳过时长需满足 `minSkipDuration ≤ 时长 ≤ maxSkipDuration`（默认 5 秒 ~ 130 分钟）。

**Q：自动连播 / 开头跳过为什么刷新后失效？**
- 这两项为页面级状态，存于 `sessionStorage`，仅当前标签页生效，符合设计预期。

**Q：弹幕获取失败？**
- 检查是否登录；部分接口需有效登录态与 WBI 签名。可开启「调试模式」在控制台查看详细日志。

**Q：支持哪些页面？**
- 视频 (`/video/`)、番剧 (`/bangumi/play/`)、合集/列表 (`/list/`)。
